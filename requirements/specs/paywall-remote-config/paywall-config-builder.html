Ngôn ngữ

Nhập JSON có sẵn

Dán giá trị hiện tại của pro_paywall_config_v1 (hoặc của một variant trong A/B test) để chỉnh tiếp. Payload sẽ nạp vào biến thể đang chọn.

Xác nhận

Từ file này tới Firebase

Publish thẳng (một payload cho tất cả)

  1. Firebase Console → Remote Config → tham số pro_paywall_config_v1 (kiểu JSON).
  2. Bấm Copy JSON ở đây, dán vào ô giá trị, Publish changes.
  3. App fetch mỗi lần mở (có minimum fetch interval). Muốn ép lấy ngay khi QC: gỡ app cài lại, hoặc đợi hết interval.

Chạy A/B test

  1. Console → A/B Testing → Create experiment → Remote Config.
  2. Mỗi variant (Baseline, Variant A…) chọn tham số pro_paywall_config_v1 và dán payload tương ứng của biến thể trong file này.
  3. Mỗi payload phải có variant KHÁC nhau — đó là nhãn đi vào analytics. Trùng nhãn thì hai nhánh không tách được trong funnel.
  4. Goal: pro_purchase_succeeded. Nhớ cắt theo user property paywall_variant, không chỉ theo event pro_paywall_viewed.

Cảnh báo

firebase deploy --only remoteconfig thay toàn bộ template — dùng Console cho việc sửa một key. Ảnh hero mới tới máy user chậm một lần mở app (chỉ đổi sau khi file đã nằm trong cache).
