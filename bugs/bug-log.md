# Bug Log — Hệ thống Quản lý vụ việc CACK Nội Bài

> Một file duy nhất cho toàn bộ bug của mọi flow, sort theo ngày phát hiện (mới nhất ở dưới).
> `Flow` / `Screen` dùng đúng tên trong [`.claude/rules/screenshot-naming.md`](../.claude/rules/screenshot-naming.md) §7.
> Nội dung viết tiếng Việt; **tiêu đề section và tên field giữ tiếng Anh** vì `scripts/` đọc đúng các khoá này.
> ⚠️ Không ghi dữ liệu cá nhân thật (họ tên, CCCD/hộ chiếu, ngày sinh, chữ ký) — chỉ dữ liệu test.
> Bug log của dự án Ink cũ: `3ada18a:bugs/bug-log.md` (`git show 3ada18a:bugs/bug-log.md`).

**Severity:** `Critical` chặn luồng chính / mất dữ liệu / lộ dữ liệu cá nhân / sai quyền · `High` sai chức năng chính · `Medium` sai hành vi phụ, có workaround · `Low` UI / cosmetic.
**Status:** `Open` · `Confirmed` · `Fixed` · `Won't fix` · `Need info`.
